# Cybersecurity Lab Assignments

This repository contains documentation and reports for cybersecurity lab assignments completed as part of coursework.

## Contents

- **File**: Race_condition_vulnerability.pdf

- **Objective**: Understanding privilege escalation through race conditions

- **File**: Tcp_attack_using_syn_flooding.pdf
- **Topic**: Denial of Service (DoS) attacks via TCP protocol
- **Objective**: Analyzing and executing SYN flood attacks

### 3. Firewall Exploration
- **File**: ASSIGNMENT_CS_1_1_.docx

- **Objective**: Building packet filtering firewalls

### 4. Network Security Assignment
- **File**: ASSIGNMENT_CS_2.docx
- **Topic**: Advanced networking and security protocols
- **Objective**: Understanding modern security implementations

### 5. Bonus Assignment
- **File**: BONUS_ASSIGNMENT.docx

- **Objective**: Extending knowledge beyond core curriculum
